# VladUZH Tap

## How do I install these formulae?

`brew install vladuzh/tap/<formula>`

Or `brew tap vladuzh/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "vladuzh/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
